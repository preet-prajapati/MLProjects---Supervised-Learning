# Reuse and licensing status

The original repository did not contain a license. This cleanup does not invent licensing
permission or assign a license on the author's behalf. Public visibility alone does not grant
unrestricted reuse rights. Contact the repository owner for permission to reuse its code.

The six inherited CSVs have unverified original provenance and redistribution terms. Dataset rights
are separate from code rights. See `docs/DATASETS.md` before using or redistributing the data.
Third-party libraries retain their own licenses.
